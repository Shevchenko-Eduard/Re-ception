# Re-ception

Репозиторий с курсовой работой студентов 3 курса Шевченко Э., Титова М. и Турищева И. по дисциплине «Разработка кода информационных систем».

Проект работает на:

- linux
- Windows 10/11 (требуется запускать скрипты через git bash и даже так результат не гарантирован)

Системные требования:

- 2+ ядра современного CPU (4+ потока)
- RAM 5+ Gb
- Docker 29.0+
- Docker compose 2.20.0+
