# Что реализовано и на каком уровне

## Nginx

Проксирование запросов к нужным сервисам извне.

## Keycloak

Реализована и настроено для работы с backend напрямую и frontend через обратный прокси сервер.

### Postgres for keycloak

Базовая настройка.

### Terraform

Базовая настройка keycloak с несколькими realms, а так же клиентами для них.

## Backend

Для возможностей смотреть приложение с checklist.

### Redis

Кеширование на уровне запросов а так де информации внутри приложения.

### MinIO

Хранение изображений.

### Postgres for backend

Базовая настройка.

### WebAPI for employee

Реализованы все необходимые CRUD операции (задачи на изменение данных оформлены в виде стандартных контроллеров в стиле REST API в то время как запросы на чтение реализованы при помощи GraphQL)

### WebAPI for customer

Реализованы все необходимые CRUD операции (задачи на изменение данных оформлены в виде стандартных контроллеров в стиле REST API в то время как запросы на чтение реализованы при помощи GraphQL)
